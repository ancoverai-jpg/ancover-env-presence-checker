# Contributing

Explain a reproducible task and use synthetic values only. Run `node --test tests/check.test.mjs` and the README example. Add behavioral regressions for parser or reporting changes, including stdout/stderr value non-disclosure. Preserve the explicit-key-only process contract and no-write/no-execution behavior. Do not broaden dotenv syntax silently or equate CLI checks with agent trigger evaluation. Report OS, Node version, commands and unavailable coverage. New formats need separately documented demand and maintenance costs. Prefer focused pull requests.
